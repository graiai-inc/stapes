Word error rate and clinical term recall of the best on-device ASR model versus the best cloud API, per dataset. a, Word error rate (%, standard Whisper-normalized regime; see Methods) of the best on-device model and the best cloud API on each of the three clinical conversation datasets (OSCE respiratory interviews, n = 272; PriMock57 primary care, n = 57; Kazi et al. psychiatric, n = 71).
